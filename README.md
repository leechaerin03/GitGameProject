## 📌 프로젝트 개요

**정사원 키우기 - Git의 시작**은  
Unity 기반으로 제작한, **Git 입문자를 위한 교육용 2D 게임**입니다.

- 직장인 정사원이 주인공
- 부장님 눈치를 보며(?) Git을 하나씩 배워가는 **스토리 중심 퀘스트 게임**
- **중·고등학생 ~ 성인**까지, Git이 처음인 사람도 쉽게 배울 수 있도록 설계
- GUI 기반 인터페이스로 `commit`, `branch`, `merge`, `push/pull` 등 **Git 핵심 개념을 자연스럽게 체험**

---

## 🎮 핵심 특징 (Features)

- 🧭 **탑다운 2D 이동 시스템**
  - 방향키로 움직이고, 정면의 오브젝트와 상호작용하는 고전 RPG 스타일 조작감

- 🗨️ **대화 & 퀘스트 시스템**
  - `TalkManager`, `QuestManager`를 통해
  - NPC와의 대화에 따라 퀘스트가 진행되고, Git 개념을 단계적으로 학습

- 📚 **Git 개념 학습 구조**
  - 에피소드별로 Git 기초 개념을 스토리 속에 녹여 설명
  - 예:  
    - 1차 퀘스트: Git이 뭔지, 왜 써야 하는지  
    - 2차 퀘스트: 브랜치(branch) 개념  
    - 3차 퀘스트: merge 충돌 상황  
    - 4차 퀘스트: push / pull 협업 흐름 등

- 🎨 **직접 제작한 도트 그래픽 & 교안 자료**
  - `Aseprite`로 제작한 캐릭터/맵 리소스
  - 수업용으로 활용 가능한 **교안 PPT**까지 함께 구성

## 👩‍💻 역할 (My Role)

### 🧠 기획 & 디자인
- 게임 전체 콘셉트/스토리 기획
- Git 교육용 **교안 및 게임 시나리오 설계**
- 인게임 에셋 리소스 **도트 그래픽 제작**

### 🕹 게임 개발
- 기본 **탑다운 이동 & 상호작용 시스템** 구현
- `퀘스트 시스템`, `대화 시스템`, `GameManager` 설계 및 구현
- 시작 화면 및 전체 흐름을 제어하는 **GameManager 로직 구현**

### 📝 기타
- 교안 PPT 제작
- 발표용 PPT 제작 및 시연
